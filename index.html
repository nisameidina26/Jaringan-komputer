Peralatan & Komponen Praktikum

Komponen utama yang digunakan dalam proses perakitan kabel dan pengujian jaringan.

Kabel UTP

Unshielded Twisted Pair (Cat5e/Cat6) sebagai media transmisi fisik data.

Konektor RJ-45

Konektor standar modular untuk terminasi ujung kabel UTP.

Tang Crimping

Alat pemotong, pengupas kabel, dan pengunci pin konektor RJ-45.

LAN Tester

Alat penguji kontinuitas sinyal transmisi pada pin kabel LAN.

Langkah Kerja & Konfigurasi

Prosedur teknis perakitan hingga proses transfer data antar perangkat.

Langkah 01

Merangkai Kabel UTP (Standar Cross-Over)

Kupas jaket luar kabel UTP sepanjang 2 cm. Untuk menghubungkan 2 laptop secara langsung (Peer-to-Peer), susun pin kabel dengan standar Cross-Over:

Ujung A (Standar T568A):
1. Putih-Hijau
2. Hijau
3. Putih-Orange
4. Biru
5. Putih-Biru
6. Orange
7. Putih-Cokelat
8. Cokelat
Ujung B (Standar T568B):
1. Putih-Orange
2. Orange
3. Putih-Hijau
4. Biru
5. Putih-Biru
6. Hijau
7. Putih-Cokelat
8. Cokelat

Setelah urutan rapi di kedua ujung kabel, potong rata lalu jepit (*crimp*) menggunakan Tang Crimping ke dalam konektor RJ-45.

Langkah 02

Pengujian Menggunakan LAN Tester (Kabel Cross-Over)

Masukkan kedua ujung kabel RJ-45 ke port Master dan Remote pada LAN Tester, lalu nyalakan alat. Karena menggunakan standar Cross-Over, indikator lampu LED akan menyala secara menyilang (cross) sebagai berikut:

Indikator Nyala Lampu LED (Master vs Remote):
Pin 1 → Pin 3
Pin 2 → Pin 6
Pin 3 → Pin 1
Pin 4 → Pin 4
Pin 5 → Pin 5
Pin 6 → Pin 2
Pin 7 → Pin 7
Pin 8 → Pin 8

Jika lampu 1-3, 2-6, dan 3-1 menyala sesuai urutan silang di atas dan tidak ada lampu yang mati/terlewat, maka transmisi fisik kabel Cross-over dinyatakan Berhasil & Sempurna.

Langkah 03

Menghubungkan & Konfigurasi IP 2 Laptop

Tancapkan masing-masing ujung kabel ke port RJ-45 Laptop A dan Laptop B. Lakukan setting IP Static pada satu segmen jaringan yang sama:

Laptop A: IP Address: 192.168.1.1 | Subnet Mask: 255.255.255.0

Laptop B: IP Address: 192.168.1.2 | Subnet Mask: 255.255.255.0

Buka Command Prompt (CMD) di Laptop A dan ketik ping 192.168.1.2. Jika muncul balasan Reply from..., koneksi fisik dan logis antar laptop telah berhasil terhubung!

Langkah 04

Cara Sharing File Melalui Kabel LAN

  1. Masuk ke Control Panel > Network and Sharing Center > Advanced sharing settings. Matikan Password protected sharing.
  2. Pilih Folder yang ingin dibagikan, klik kanan > Properties.
  3. Pilih tab Sharing > Klik tombol Share...
  4. Pilih opsi Everyone, klik Add, atur Permission Level ke Read/Write, lalu klik Share.
  5. Di laptop penerima, buka File Explorer, ketik alamat IP laptop pengirim pada address bar (contoh: \\192.168.1.1) untuk mengakses file secara langsung.
